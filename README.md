# Jogo da Cobrinha
Recriando o clássico jogo da cobrinha usando circuitos lógicos através do simulador de circuitos Logisim
## Versão do simulador
logisim-win-2.7.1
[Site oficial](https://www.cburch.com/logisim/)
## Como jogar?
- Instale o Logisim
- Abra o arquivo .circ no simulador(Arquivo -> Abrir...)
- Selecione a página "main", na árvore de arquivos. Clique nela com o botão direito duas vezes para abrir.
- Certifique-se que o simulador está rodando e que o pulso está habilitado(Simular -> Habilitar simulação e Simular -> Pulso Habilitado)
- Aumente a frequência do pulso para 256Hz(Simular -> Frequência de pulso -> 512Hz)
- Clique no botão "S" para iniciar o jogo e controle o personagem com os botões direcionais
